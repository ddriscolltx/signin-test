Add the connector

  1. In Claude (claude.ai, in a desktop browser): Settings, then Connectors, then add a custom connector.
    In ChatGPT (chatgpt.com, in a desktop browser): Settings, then Apps and connectors, then create a connector.
  2. Give it this address: https://shopvisor-signin-spike-704240202919.us-central1.run.app/mcp
  3. When the sign-in window opens, enter your email address, then the code we email you.
  4. Approve what the assistant asks to do.
